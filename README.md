# controle-de-gastos-typebot
Sistema de controle de gastos automatizado desenvolvido com Typebot e Google Sheets, com categorização, forma de pagamento, identificação automática do mês e resumo financeiro
Sobre o projeto
Sistema desenvolvido para facilitar o registro e acompanhamento de despesas pessoais através de uma interface conversacional.

Funcionalidades

Registro de despesas
Categorias de gastos
Forma de pagamento
Identificação automática do mês
Confirmação antes de salvar
Edição do lançamento
Cancelamento e reinício
Integração com Google Sheets
Totais mensais
Gastos por categoria
Resumo anual
Identificação da categoria com maior gasto

Tecnologias

Typebot
Google Sheets
JavaScript para tratamento de data/mês
Automação e lógica condicional

Fluxo
Usuário → Tipo de gasto → Valor → Pagamento → Data → Mês → Conferência → Google Sheets
